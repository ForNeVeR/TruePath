# BCL methods that must not be exposed as PathIo extension methods.
#
# One XML documentation ID per line, e.g.:
#     M:System.IO.Directory.Delete(System.String,System.Boolean)
#
# Methods covered by user-defined PathIo members are excluded automatically and
# must not be listed here. This holds both for user-defined members occupying
# the same rewritten signature (e.g. CreateDirectory), and for user-defined
# members whose body forwards to the BCL method with `path.Value` as the first
# argument (e.g. DeleteEmptyDirectory/DeleteDirectoryRecursively forwarding to
# Directory.Delete(string, bool)).
#
